Cara Simpan Terus ke Google Sheets

Anda mempunyai 2 cara untuk menyimpan rekod ke dalam Spreadsheet:

Cara 1: Eksport Fail CSV (Paling Mudah)

Klik butang hijau "Muat Turun Spreadsheet (.CSV)" di jadual bawah. Fail tersebut boleh terus dibuka menggunakan Microsoft Excel atau dimuat naik (Import) ke dalam Google Sheets anda.

Cara 2: Sambungan Automatik (Google Apps Script)

Jika anda mahu setiap tempahan terus masuk ke Google Sheets dalam gambar anda secara automatik:

  1. Buka Google Sheets anda, klik menu Extensions > Apps Script.
  2. Padam kod sedia ada dan tampal kod skrip di bawah:
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([
    data.nama + " (" + data.telefon + ")",
    data.original,
    data.choc,
    data.mix,
    data.puding,
    data.total
  ]);
  return ContentService.createTextOutput("Berjaya");
}
  1. Klik Deploy > New deployment, pilih jenis Web app, set akses kepada Anyone, dan salin URL Web App tersebut.
